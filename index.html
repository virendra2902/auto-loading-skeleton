SkeletonProvider + AutoSkeleton
import { SkeletonProvider, AutoSkeleton } from 'auto-loading-skeleton-v2';

// Wrap your app once — all AutoSkeletons inherit these defaults
function App() {
  return (
    <SkeletonProvider
      animation="shimmer"
      theme="soft"
      fadeIn={true}
    >
      <ProductPage />
    </SkeletonProvider>
  );
}

function ProductPage() {
  const { data, loading } = useSkeletonData(() => fetchProduct());

  return (
    <AutoSkeleton
      loading={loading}
      onLoaded={() => console.log('ready!')}
    >
      <ProductCard product={data} />
    </AutoSkeleton>
  );
}

V2 ships 4 hooks for every loading scenario. All are composable and SSR-safe.

useSkeleton
(initial?, opts?) → {loading, setLoading, skeletonProps}
Basic loading state manager. skeletonProps spreads directly onto AutoSkeleton.
useSkeletonDelaynew
(loading, delay=200) → boolean
Prevents skeleton flash. Only returns true if loading has lasted longer than delay ms. Perfect for fast APIs.
useSkeletonTimeoutnew
(loading, minDuration=500) → boolean
Ensures skeleton stays visible for at least minDuration ms. Prevents jarring instant transitions when data arrives too fast.
useSkeletonDatanew
<T>(fetchFn, deps?) → {data, loading, error}
Async data fetcher fully integrated with loading state. Cancels in-flight requests on unmount. No extra state needed.
useSkeletonData — async data + loading in one hook
import { useSkeletonData, AutoSkeleton } from 'auto-loading-skeleton-v2';

function UserCard({ userId }) {
  const { data: user, loading, error } =
    useSkeletonData(() =>
      fetch(`/api/users/${userId}`)
        .then(r => r.json()),
      [userId]  // re-fetches when userId changes
    );

  if (error) return <ErrorState error={error} />;

  return (
    <AutoSkeleton loading={loading}>
      <ProfileCard user={user} />
    </AutoSkeleton>
  );
}
